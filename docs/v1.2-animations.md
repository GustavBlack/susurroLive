## 0. Non-negotiable house rules (from `viz.js` today)

Every new animation must obey these — they are why the grid feels "woven, not busy":

1. **Deterministic fields.** Everything is a pure function of `(x, y, elapsedSeconds)`. No
   per-frame random, no frame-count particles. A fixed seed via `hash2()` is the only randomness.
2. **Elapsed-clock, not wall-clock.** Background time never advances a wave; large rAF gaps
   resume gently (`clock += min(elapsed, 0.1)`).
3. **State lives in `pixels[]`, blended per-frame** (`blend = 1 - exp(-dt/τ)`) — mode switches
   are always smooth dissolves, never cuts.
4. **`prefers-reduced-motion`:** ambient fields freeze to a static frame (t = 4.5); essential
   audio feedback continues at 10 Hz. New ambient behavior must degrade the same way.
5. **No per-tile filters/shadow blurs** — halos are two explicit fillRects. Keep per-tile cost
   to trig + value noise only; ~500 tiles × 60 fps is the budget.
6. **Color discipline:** ink→amber→accent→pale ramp (`ramp()`), sage/moss family for
   processing/success, rust for error, muted grey for muted sources.

## 3. Scope

### A. Idle field expansion — 4 → 8 fields with choreography

New fields (same signature `(x, y, t) → energy`, same ramp):

1. **Ember drift** — 5–6 hash-seeded embers on slow Lissajous paths; each a gaussian spot with a
   sine fade envelope (fade-in/out on the cycle so the dissolve joins cleanly).
2. **Ink in water** — domain-warped value noise: `noise(x*2 + warp(t), y*2 - t*0.05)` where
   `warp = (noise(t*0.06) - 0.5) * 1.5`; soft threshold for blobby pools. Lava-lamp calm.
3. **Aurora curtain** — 2 vertical gaussians whose x sways by layered sines; intensity modulated
   along y by low-freq noise; faint vertical streak texture.
4. **Tide** — one horizontal bright line ("foam") drifting up/down by `sin` + noise perturbation,
   with a broad gaussian body below it; slowest field of the set.

Choreography:
- **Per-field dwell** instead of fixed 18 s: schedule array `{field, dwell}` — calm fields 22 s,
  active ones 14 s; rotation stays fixed-order (the dissolve-join guarantee), the *duration*
  varies. `IDLE_CYCLE` becomes computed from the schedule.
- **No adjacent repeats:** the schedule is a hand-ordered loop, including across the last→first
  join.

### B. Scroll-reactive "reading current" (the headline feature)

A new *input path*, not a new mode — energy layered onto idle/paused:

- **API:** `viz.setScrollVelocity(v)` — signed magnitude (px/s, clamped), called from the
  existing `txBox` scroll listener in `app.js` (which already tracks follow state).
- **Behavior:** tiles brighten with a directional advected streak field flowing *opposite* to
  the scroll direction — reading down pulls light down, like sliding a lamp along the rail.
  Envelope: fast attack (~50 ms), long release (~0.9 s), so the grid exhales when you stop.
- **State rules:** applies only in `idle`/`paused`; `capture`/`playback`/`import` ignore it
  (audio keeps priority). Zero effect when `prefers-reduced-motion`.
- **Cost:** one extra noise eval per tile, only while `|energy| > 0.01`; decays to exactly the
  plain idle frame afterwards.

### C. Progress-aware import + transcription pulses

- **`viz.setImport(progress01)`** — the import field gains a **wavefront line**: tiles below the
  progress height carry the full rising currents, tiles above stay dim ink. The grid visibly
  fills as the file transcodes. `app.js` already receives import progress events
  (`onProgress('import', …)`).
- **Completion sweep** — when import/transcription finishes, one soft top-to-bottom wash
  (~1.2 s), then settle to idle. A named "done" moment instead of an abrupt stop.
- **Chunk pulse** — `viz.pulse()` on `chunk:done`: a single gaussian band traveling down the
  grid, decaying ~2.5 s. Recording keeps its column levels; the pulse is an overlay so it reads
  as a heartbeat, not a mode change. On `chunk:error`, one rust-tinted pulse.

### D. CSS pattern accents (small, from the knowledge files)

1. **Static grain** — inline SVG `feTurbulence` as a fixed, non-animated background layer on the
   app background (anti-banding, ~4% opacity, no filter boost).
2. **Pipeline "running" shimmer** — Afif-style `background-position` keyframe on the active
   chunk chip only (sage family); compositor-only, pauses under reduced motion.
3. **DEMO-mode backdrop** — a faint animated pattern behind the banner so demo output is
   unmistakable at a glance (safety feature, not decoration).

### E. Transition polish

- **Ignition (idle → capture):** an 0.8 s bottom-up accent sweep as the record button engages,
  then levels take over. Implemented as a time-gated additive band inside capture mode
  (`age < 0.8`), so it needs no new state.
- Capture → idle and capture → paused already dissolve via the shared `pixels[]` blend; no work.

## 6. Test plan (extensions to `tools/test-viz.js`)

- All 8 fields render finite, non-empty pixels — advance the clock past every schedule slot
  *and* through a crossfade window.
- Scroll: `setScrollVelocity(±600)` changes pixels; after 3 s of zero velocity the frame matches
  plain idle again (release works, no residue).
- Import wavefront: tiles above `progress` darker than below; progress 1.0 + sweep ends within
  ε of the idle frame.
- Pulse: transient pixel change that fully decays; rust tint distinguishable on error pulse.
- Reduced motion: scroll input produces **zero** delta; fields render one static frame.
- Perf: average frame time < 8 ms over 300 forced frames with scroll energy active.
- Existing checks must stay green (paused settles still, 30 vs 60 fps equivalence, finite pixels).

## 7. Risks

| Risk | Mitigation |
| --- | --- |
| 8 fields × 500 tiles pushes frame budget | fields are 3–5 trig/noise evals each; measure in the Phase F perf check before adding more |
| Scroll listener fires at input rate | throttle: accumulate delta, sample velocity once per rAF in `viz.draw` |
| Wavefront makes long imports look "stuck" | minimum creep animation (slow ambient shimmer above the line) so the grid never freezes |
| New fields clash with the palette | all fields render through the existing `ramp()`; no new colors introduced in canvas work |
| Reduced-motion regressions | every feature has an explicit reduced-motion behavior; test plan asserts them |

## 8. Explicitly out of scope (v1.2)

- Speaker diarization, `.srt`/`.vtt`, resident model, overlap windows (still v2 — unchanged).
- Any rewrite of capture/pipeline layers — v1.2 is renderer-only (`viz.js` + `app.js` + CSS).
- User-configurable animation themes (possible v1.3: "field packs").
