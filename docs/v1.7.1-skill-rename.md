# susurroLive v1.7.1 — Hermes skill renamed to `susurro-live-mcp`

**A packaging fix, not a feature release.** No app behaviour, no MCP surface, no session-format
change. If you never install the Hermes skill, v1.7.1 is identical to v1.7.0 in use.

## Why

v1.7.0 shipped its MCP-control skill as `susurro-live`, which collides with the skill many people
already keep for working on this source tree. Hermes resolves skills by their frontmatter `name:`:

- two skills declaring the same `name:` cannot both load — one **silently shadows** the other;
- the shadowed skill becomes unreachable (`skill_view` cannot address it);
- which one wins depends on discovery order, so the failure looks random.

The installed skill was renamed to **`susurro-live-mcp`** on the machine where this was found; the
repo copy, the packaged copy, and every doc now agree.

## What changed

| | v1.7.0 | v1.7.1 |
| --- | --- | --- |
| Skill name | `susurro-live` | **`susurro-live-mcp`** |
| Repo path | `integrations/hermes/susurro-live/` | `integrations/hermes/susurro-live-mcp/` |
| Packaged path | `resources\hermes-skill\susurro-live\` | `resources\hermes-skill\susurro-live-mcp\` |
| Install path | `%LOCALAPPDATA%\hermes\skills\audio\susurro-live\` | `...\skills\audio\susurro-live-mcp\` |
| Skill version | 0.1.0 | 0.2.0 |

Convention, now stated in the skill itself: **`susurro-live-mcp` drives the running app;
`susurro-live` (if you keep one) maintains the source.** Directory name and frontmatter `name:`
must stay identical — do not rename the folder on copy.

`npm run test:skill` now fails if the name drifts from the directory or loses the `-mcp` suffix, so
this cannot regress quietly.

## Upgrading from v1.7.0

The installer update does not touch your Hermes skills directory. If you installed the v1.7.0
skill, remove the old copy and install the new one:

```powershell
Remove-Item -Recurse "$env:LOCALAPPDATA\hermes\skills\audio\susurro-live" -ErrorAction SilentlyContinue
Copy-Item -Recurse "<install>\resources\hermes-skill\susurro-live-mcp" "$env:LOCALAPPDATA\hermes\skills\audio\susurro-live-mcp"
```

The skill's own contents are otherwise unchanged: same 18 MCP tools, same `scripts/susurro.ps1`
subcommands, same bearer token from `%APPDATA%\susurroLive\mcp.json`.

## Install

- **Recommended:** `susurroLive-Setup-1.7.1.exe` — per-user installer; sessions survive uninstall.
- **Portable:** `susurroLive-1.7.1-portable.exe` — one exe, no install, no update feed.

See [`v1.7.0-mcp-agent-control.md`](v1.7.0-mcp-agent-control.md) for the MCP feature itself.
