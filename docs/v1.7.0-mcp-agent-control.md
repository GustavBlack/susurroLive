# susurroLive v1.7.0 — agent control (MCP)

**A local MCP server inside the app.** When susurroLive is open, an agent can start/stop
recordings, choose where the session lives, add microphone/system sources by profile, wait for
transcription, and read or export the transcript. No second process, no cloud, no MCP framework
dependency.

## What an agent can do

- `recording_start {profile:"meeting", parentDir:"D:/Sessions", name:"Weekly Sync"}` creates the
  timestamped session folder and starts **default microphone + system loopback**.
- `profile:"voice"` records only the default microphone; `profile:"system"` records only system
  audio; `profile:"custom"` takes an explicit source array.
- `recording_pause` / `recording_resume` / `recording_stop` mirror the UI transport.
- `recording_stop {waitForTranscription:true}` closes the final chunk, builds `full.wav`, drains
  the chunk queue, and reports errors.
- `transcript_get` returns prose or timecoded JSON words/segments, with the corrected projection
  by default; `export_run` writes `.txt`, `.json`, or audio.
- `session_list` / `session_open` / `session_create`; `import_media`; `diarize_run`; `settings_set`.

Full reference: [`docs/mcp.md`](mcp.md).

## Two ways to connect Hermes

1. **Native MCP tools** — paste the generated `mcp_servers` YAML into
   `%LOCALAPPDATA%\hermes\config.yaml`; tools appear as `mcp_susurro_*`.
2. **Skill, no MCP registration** — install `integrations/hermes/susurro-live/`; the skill runs
   `scripts/susurro.ps1`, which launches the app if needed and calls the same endpoint. Native
   Windows only; requires the `terminal` toolset.

## Security

- Server binds `127.0.0.1:8790` only; `Host` allowlist and no browser `Origin`.
- Bearer token (32 random bytes) in `%APPDATA%\susurroLive\mcp.json`; never sent to the renderer
  or logs. Rotate from Settings → Agents (MCP).
- 1 MiB request cap; fixed tool allowlist; no shell/exec tool; no LLM key access.
- An agent with the token can record and read transcripts. Disable the toggle to revoke.

## Reliability

- Main owns session/pipeline truth; capture commands go through a named renderer channel, so the
  UI and agent cannot diverge.
- `backgroundThrottling:false` keeps capture/chunking alive when the window is minimized.
- Renderer crash mid-recording finalizes the session instead of leaving it "recording".
- Session folders are collision-safe (`-2`, `-3`) when created in the same second.

## Install

- **Recommended:** `susurroLive-Setup-1.7.0.exe` — per-user installer; sessions survive uninstall.
- **Portable:** `susurroLive-1.7.0-portable.exe` — one exe, no install, no update feed.

available.
